# 合记 ChemLab —— 安装与使用说明

> 版本 0.11.2 ｜ 单机离线工具 ｜ 内部使用

---

## 一、安装（3 步）

### 第 1 步：导入信任证书（一次性，30 秒）

双击收到的 **`ChemLab-CodeSigning.cer`** 文件：

1. 右键 → **「安装证书」**
2. 「本地计算机」→ 下一步（需管理员权限）
3. 「将所有证书放入下列存储」→ 选 **「受信任的根证书颁发机构」** → 下一步 → 完成

> **为什么需要这步？**
> 本应用由内部打包工具构建，不是商业软件，没有购买商业代码签名证书。
> 这一步是把「内部自签名证书」加入系统信任列表，效果等同于商业证书，
> 区别只是需要手动导入一次。
>
> **IT 批量下发**：在域策略里导入这个 `.cer` 即可全公司生效，无需逐台操作。

### 第 2 步：运行安装包

双击 **`合记 ChemLab_0.11.2_x64-setup.exe`**，按提示一路「下一步」。

- 安装位置默认 `C:\Program Files\合记 ChemLab\`
- 无需管理员权限（安装到当前用户目录）
- 桌面与开始菜单会生成快捷方式

### 第 3 步：启动

从桌面快捷方式启动。**首次启动需要等 5~15 秒**——应用会自动拉起内部的数据服务
（界面右下角显示「后端运行中」即就绪）。

## 二、常见问题

### Q1：杀毒软件报毒 / 拦截

**大概率是误报。** 本应用是单机离线工具，不联网、不上传数据、不注册开机自启。

处理办法（按优先级）：

| 做法 | 操作 |
|---|---|
| **加白名单**（推荐） | 在杀软设置里把安装目录 `C:\Program Files\合记 ChemLab\` 加入信任区/白名单 |
| **允许运行** | 在「保护历史记录」里找到被拦截项 → 「允许在设备上」 |
| **排除安装目录** | Windows 安全中心 → 保护历史记录 → 排除项 → 添加文件夹 |

误报的成因与已做的规避措施见技术文档 `docs\杀软误报说明.md`。

### Q2：Windows 提示「Windows 已保护你的电脑」

说明第 1 步的证书没导入成功，或导入时选了「当前用户」而不是「本地计算机」。
**先做第 1 步**，然后重新运行安装包。

### Q3：启动后界面空白 / 提示后端未就绪

应用的后端日志在：

```
%APPDATA%\ChemLab\logs\backend.log
```

把最后 20 行发给技术支持即可定位。

### Q4：端口 8765 被占用

启动时若提示端口被占用，说明本机有另一个 ChemLab 实例在跑（或旧版 ChemELN 残留）。
关掉旧实例后重启；或在系统环境变量里设 `CHEMLAB_PORT=8766` 换端口。

## 三、数据在哪里

| 内容 | 位置 |
|---|---|
| 实验记录、化合物库 | `%APPDATA%\ChemLab\chemlab.db`（SQLite） |
| 实验附件（谱图、照片等） | `%APPDATA%\ChemLab\attachments\` |
| 自动备份 | `%APPDATA%\ChemLab\backups\` |
| 日志 | `%APPDATA%\ChemLab\logs\backend.log` |

**备份建议**：把整个 `%APPDATA%\ChemLab\` 目录复制到网盘/共享盘即可。
应用自带定时自动备份（可在「设置」里调整周期）。

> 卸载应用**不会**删除这些数据（避免误删实验记录）。需要彻底清理请手动删除该目录。

---

## 四、卸载

控制面板 → 程序和功能 → 「合记 ChemLab」→ 卸载。

卸载会移除程序文件，**保留** `%APPDATA%\ChemLab\` 里的实验数据。
要连数据一起清掉，卸载后手动删掉该目录。

## 五、这个应用能做什么

| 模块 | 用途 |
|---|---|
| **实验记录** | 电子实验记录本：结构式（可编辑）、投料、步骤、产物、谱图附件 |
| **化合物库** | 内置 326 条常用化合物 + 三库归一数据，支持中文全文检索 |
| **溶剂库** | 98 种溶剂的物性、极性、危害信息 |
| **SOP 库** | 19 份标准操作规程模板 |
| **投料表 / 计算器** | 化学计量计算、投料表生成 |
| **纯化 / 安全** | 纯化方法速查、安全应急手册 |

**快捷键**：主界面顶部为一级导航，实验记录页内有细分视图切换。
