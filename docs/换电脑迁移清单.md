# 换电脑迁移清单

换一台电脑继续开发这个项目，需要搬的东西分四类。**第 3 类是唯一容易丢的**，先看它。

---

## 1. 代码（最重要，但目前只在本机）

现状：**仓库还没有远程**（`git remote -v` 为空），40 个提交只存在这台电脑的
`D:\DaHan\DaHantd\ChemLab\.git` 里。硬盘坏了就全没了。

**必须先做的一步**（二选一）：

```bash
# 方案 A：推到 GitHub（推荐，同时解决备份 + 开源两件事）
#   先在 GitHub 网页建一个空仓库，然后：
git remote add origin https://github.com/<你的用户名>/chemlab.git
git push -u origin master

# 方案 B：暂时不公开，先做个离线备份
cd /d/DaHan/DaHantd
git clone --mirror ChemLab ChemLab-backup.git    # 完整镜像，含所有分支和 tag
# 把这个 ChemLab-backup.git 拷到移动硬盘/U 盘，就是完整历史
```

新电脑上：

```bash
git clone https://github.com/<用户名>/chemlab.git
cd chemlab
```

## 2. 用户数据（实验记录等）

路径：`%APPDATA%\ChemLab\`

| 内容 | 大小 | 要不要搬 |
| --- | --- | --- |
| `chemlab.db` | 656 KB | **必须** — 全部实验记录、化合物、模板 |
| `attachments\` | 目前为空 | **必须** — 实验照片等附件 |
| `backups\` | 9.3 MB | 可选 — 自动备份的 db 副本 |
| `logs\` | 44 KB | 不用 |

拷法：把整个 `%APPDATA%\ChemLab` 文件夹复制到新电脑的同名位置即可。
（`Win+R` 输入 `%APPDATA%` 直达）

另外 `%APPDATA%\com.heji.toolbox\` 里是主壳的启动日志，不用搬。

## 4. 开发环境

| 工具 | 版本 | 说明 |
| --- | --- | --- |
| Node.js | ≥ 20（本项目实测 22.22.2） | 前端构建 |
| Python | 3.13 | 后端，装 `backend/requirements.txt` |
| Rust | stable | 仅打包需要（`npm run dev` 不需要） |
| Git | 任意 | — |

### 新电脑首次跑起来

```bash
# 前端
npm install          # 用 npm，不要用 pnpm（Windows 符号链接问题，见 README）

# 后端
cd backend
python -m venv venv
venv/Scripts/pip install -r requirements.txt
venv/Scripts/python main.py --port 8765

# 另开终端
npm run dev          # 浏览器版，最轻
npm run tauri dev    # 带壳桌面版
```

打包：

```bash
powershell -ExecutionPolicy Bypass -File build/build.ps1 -Fast
```

首次打包会编译 Rust 依赖，约 10–15 分钟；之后增量 7 分钟左右。

## 迁移后的验收清单

在新电脑上逐条确认：

- [ ] `git log --oneline | wc -l` 显示 40+ 条提交（历史完整）
- [ ] `%APPDATA%\ChemLab\chemlab.db` 存在，且打开应用能看到原有实验记录
- [ ] `npm run dev` 能起前端，`/toolbox/` 打开正常
- [ ] 后端 `/api/health` 返回 200
- [ ] 结构式能渲染（输 `CCO` 看是否出图）
- [ ] `build\build.ps1` 能正常打包（默认不签名）
