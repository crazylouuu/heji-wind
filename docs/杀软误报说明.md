# 杀软误报说明（P6）

## 一句话结论

如果你的杀毒软件拦住了「合记 ChemLab」，**多半是误报**。
本应用用 PyInstaller 打包 Python 后端，这类打包产物的文件特征与常见恶意软件高度重合，
在没有代码签名的情况下被启发式引擎判为可疑是常见现象。

本应用**不联网、不上传数据、不注册开机自启、不做进程注入**，
全部功能都在本机离线完成。

> **本版本已做数字签名**（自签名，见 `build/sign.ps1`）。
> 安装包、主程序、后端 sidecar 三者均已签名，带 DigiCert 时间戳。
> 同事机器上首次安装需先导入一次 `build/ChemLab-CodeSigning.cer`
> （一步操作，说明见 `docs/给同事的安装说明.md`），之后不会再出现
> 「Windows 已保护你的电脑（未知发布者）」提示。

## 为什么会被误报

| 因素 | 说明 |
| --- | --- |
| PyInstaller bootloader | 打包出的 exe 会把 Python 解释器与依赖塞进自身并在运行时解压执行，这个行为与许多恶意软件的加载器相似 |
| 无数字签名 | 未购买证书签名的 exe 默认可信度低，启发式引擎更容易"保守判黑" |
| 打包体积大 | 单文件 16MB + 189MB 依赖目录，形态上不像普通应用 |
| 子进程行为 | 主程序会 spawn 一个子进程（后端服务），某些规则对"父进程拉起未签名子进程"敏感 |

## 我们已经做的降低误报处理

| 措施 | 效果 |
| --- | --- |
| **数字签名**（自签名） | 安装包/主程序/sidecar 均已签名且带时间戳；给启发式引擎一个可校验的签名特征，显著降低误判 |
| **onedir 而非 onefile** | 依赖不压缩进单个 exe，运行时也不需要解压到临时目录 —— 这是杀软最敏感的行为，已规避（沿用合迹版已验证的结论） |
| **不使用 UPX 压缩** | UPX 加壳是误报重灾区，spec 里 `upx=False` |
| **不使用自解压/自修改** | 无自修改代码行为 |
| **只监听回环地址** | 后端只绑 127.0.0.1，局域网无法连接；配合会话令牌鉴权 |
| **行为可审计** | 全部数据在 `%APPDATA%\ChemLab`，日志在 `%APPDATA%\ChemLab\logs\backend.log` |

## 如果被拦截，怎么处理

### 方案 A：加白名单（推荐）

**Windows Defender（Microsoft Defender 安全中心）**

1. 打开「Windows 安全中心」→「病毒和威胁防护」→「保护历史记录」
2. 找到被拦截的项 → 选择「允许在设备上」
3. 或在「管理设置」→「排除项」中添加：
   - 文件夹排除：`C:\Program Files\合记 ChemLab\`

**第三方杀软**（360 / 火绒 / 腾讯电脑管家等）通用做法：
在「信任区 / 白名单 / 信任的文件」里添加安装目录：
```
C:\Program Files\合记 ChemLab\
```

> 只排除**安装目录**即可；排除整个 Program Files 不必要。

### 方案 B：添加排除项（预防性）

在打包/分发时，可以提前告知用户添加排除项，避免首次启动就被拦。

### 方案 C：代码签名（已部分完成）

**已完成的部分**：本项目已实现自签名流程（`build/sign.ps1`），
安装包、主程序、后端 sidecar 三者均已签名并带 DigiCert 时间戳。
自签名证书已导出为 `build/ChemLab-CodeSigning.cer`，同事导入一次即可永久信任。

**自签名的局限**：自签名证书不在任何公共信任列表里，
所以**别人机器上不导入证书仍会显示"未知发布者"**。
它的价值是：给了杀软一个可校验的签名特征（显著降低启发式误判），
并且让同事只需一次导入就能长期正常使用。

**彻底方案**：购买 OV/EV 代码签名证书并签名，
这样任何人双击都能直接安装，不需要任何额外操作。
代价：证书年费数千元。内部小范围分发不需要。

## 被拦截后的排查步骤

1. **看日志**：后端日志在
   ```
   %APPDATA%\ChemLab\logs\backend.log
   ```
   若应用能启动但实验记录页打不开，这里通常能看到具体错误。

2. **看设置页状态**：「我的 → 后端服务」会显示后端是否就绪、失败原因与日志路径。

3. **确认端口未被占用**：后端默认 8765 端口。若被其它程序占用，
   主壳会明确报「端口已被占用」，可设置环境变量 `CHEMLAB_PORT` 换端口。

4. **手动跑后端**（绕过主壳）：
   ```
   cd "C:\Program Files\合记 ChemLab\resources\backend"
   ChemLabBackend.exe --port 8765
   ```
   若这一步就被杀软拦下，确认是误报并加白名单。

## 给 IT / 管理员的说明

本应用是**单机离线工具**：

- 不含网络客户端代码，不向任何服务器发送数据
- 唯一的网络行为是监听本机回环地址 `127.0.0.1:8765`（供主界面与后端通信）
- 数据文件全部位于 `%APPDATA%\ChemLab\`（SQLite 库、附件、备份、日志）
- 安装包由 Tauri NSIS + PyInstaller onedir 组成，无自启动项、无服务注册
- 可随时卸载：控制面板 → 程序和功能 → 卸载（用户数据保留在 `%APPDATA%\ChemLab\`，需手动删除）
