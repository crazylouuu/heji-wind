> 评估时间：2026-10-23 ｜ 方式：读代码 + 做 PoC 实测，不是拍脑袋

## 结论先说

**技术上可行，而且核心已经跑通了。** 我把工具箱前端挂到后端 `/toolbox/` 下，
浏览器实测：导航、工作台、6 张功能卡、近期实验（真实数据）全部正常，**控制台 0 错误**。

还要补 4 类功能，估计 **1 个工作日**。但有一个前提必须先讲清楚：

> **即使完全不装壳，Python 后端（62MB 的 sidecar）仍然必须安装。**
> "移到后端"不等于"变成纯网页"，而是从「壳 + 后端」变成「后端 + 浏览器」。

## 四、代价（必须提前接受）

| 失去的东西 | 具体影响 |
| --- | --- |
| **双击即用** | 要先用脚本/快捷方式启动后端，再打开浏览器。可以用 `scripts/lightweight-mode.bat` 缓解，但体验不如一个图标 |
| **原生窗口** | 变成浏览器标签页；没有窗口最大/最小化记忆、无边框等 |
| **通知可靠性** | 浏览器通知必须页面开着（或装成 PWA）；壳的通知是系统级的 |
| **PDF 排版** | 后端生成的 PDF 排版要重做；浏览器 `print()` 受用户"另存为 PDF"设置影响 |
| **单文件分发** | 现在是一个 62MB 安装包；改成 Web 模式后仍需装 sidecar（含 189MB RDKit），安装包体积不变 |
| **内存** | 省掉 WebView2 的 150~300MB，但换来一个浏览器标签页（约 100~200MB），**净收益有限** |

> 一个诚实的判断：**如果你的机器本来就开着浏览器，"更快"确实成立**（边际成本低）；
> 如果为了用这个软件专门开一次浏览器，其实并不比双击图标快。

## 五、三个可选方案

### 方案 A：壳降级为启动器（已实现 ✅）

保留壳，但启动后**直接打开默认浏览器**并让壳自己退出。
- 保留：双击即用、自动拉起后端
- 省掉：WebView2 的 150~300MB 内存
- 不用改前端代码（只改 Rust 启动分支）

**实现方式**：环境变量 `CHEMLAB_MODE` 三态

| 取值 | 行为 |
| --- | --- |
| `browser` | 强制启动器模式 |
| `window` | 强制完整窗口（要子 webview / 原生通知时用） |
| 未设置 | **debug 构建默认 window**（否则 `pnpm tauri dev` 一启动就退出没法调试），**release 构建默认 browser** |

**执行顺序**（顺序不能反）：

```
拉起后端 → 打开浏览器 → detach（放弃子进程所有权）→ 壳退出
```

如果反过来（先退出再 detach），退出钩子会把后端当自己的子进程杀掉，
浏览器刚打开就连接失败。

**失败回退**：后端起不来、或浏览器打不开时，**不退壳**，留在窗口模式 ——
否则用户只会看到一个 404 的标签页，毫无线索。

### 方案 B：完整 Web 化（进行中）

把剩余依赖原生能力的功能逐个搬进后端。

### 方案 C：维持现状

`CHEMLAB_MODE=window` 即为原行为。

## 五之二、实现过程中发现的两个真问题

### 问题 1：`detach` 不够 —— 后端会被连带杀掉

第一版只实现了「丢句柄」（`detach`），实测：

| 时间点 | 主壳 | 后端 |
| --- | --- | --- |
| 启动后 22 秒 | 已退出 ✅ | 存活 ✅ |
| 再等约 10 秒 | 已退出 | **消失** ❌ |

后端日志无任何异常，是被外部终止。判定实验：

| 启动方式 | 存活情况 |
| --- | --- |
| 作为壳的子进程（detach 后壳退出） | 壳退出后约 10 秒消失 |
| `Start-Process` 直接启动（脱离任何父进程） | **稳定存活 60 秒**（持续观测） |

结论：环境不是无条件回收进程，而是**父子进程连带终止**。
`detach` 只丢了 Rust 里的句柄，Windows 层面的父子/Job 关系依然存在。

**修复**：创建子进程时加 `CREATE_BREAKAWAY_FROM_JOB`（0x01000000），
让后端脱离父进程所在的 Job Object。若所在 Job 不允许 breakaway
（`ERROR_ACCESS_DENIED`），自动回退到不带该标志的创建方式 ——
不能因为一个优化让后端彻底起不来。

### 问题 2：SOP 页在浏览器里直接报错

`Cannot read properties of undefined (reading 'invoke')` ——
SOP 库、SOP 配图都还在用 Tauri 命令，浏览器里没有 `invoke`。

**修复**：新增 `/api/sop/list`、`/api/sop/file`、`/api/sop/image` 三个接口，
前端 `loadSops.ts` / `sopImages.ts` 改走 HTTP。**这样壳模式和浏览器模式行为完全一致**，
少一条分支。

安全处理：路径先 `resolve` 再校验前缀（带分隔符，避免 `/sops-extra` 误判），
越界一律 404。实测 `../../backend/config.py` → 404。

实测结果：浏览器里 SOP 库 **18 个结果正常渲染**，标签筛选、分类分组、
风险等级（medium / 待评估）全部可用，**0 console 错误**。

### 关于 PDF 导出：它其实不需要迁移

原计划里有「PDF 导出搬到后端（约 2h）」。深入看调用链后发现这条是误判：

``` 
exportPdf() 的唯一调用方是 src/components/ExperimentsPanel.vue
  → 而 ExperimentsPanel.vue 没有任何地方 import（死代码）
    → 因为 2026-09-23 就按需求停用了「实验记录面板」（数据泄露风险）
```

也就是说 **界面上早就没有 PDF 导出的入口了**，`src/views/RecordsView.vue` 现在只有
「计时器」和「检查清单」两个子 Tab。Rust 侧的 `export_pdf` 命令仍在注册表里，
但前端不调用，属于可随时恢复的休眠代码。

同样：投料表导出（`ExperimentsPanel` 里的 JSON/Markdown 导出）也是死代码。
**全项目真正在用的导出入口只有一处**：设置页的「导出状态备份（JSON）」，已改成浏览器下载。

### 通知的三种路径（实测）

| 场景 | 行为 | 实测结果 |
| --- | --- | --- |
| 已授权 | `new Notification(...)` 系统通知 | ✅ `perm=granted ctor=ok` |
| 用户拒绝过 | 不再弹窗，改「标题闪烁约 10 秒」 | ✅ `perm=denied`，0 错误 |
| 浏览器不支持 | 同样走标题闪烁 | 逻辑覆盖 |

注意 `requestPermission()` 必须在用户手势里调用，所以放在「开始计时」这个点击事件里 ——
页面加载时就请求会被浏览器直接判为 denied。

## 七、启动器模式的日常使用

### 怎么启动

双击桌面「合记 ChemLab」→ 等 7~25 秒（首次更久）→ 浏览器自动打开
`http://127.0.0.1:8765/toolbox/` → 壳自己退出。

任务栏里**不会**留下应用图标（壳已退出），这是预期行为。
后端在后台运行，浏览器标签页可以正常使用。

### 怎么彻底关闭

后端是独立进程，壳退出后它还在跑。两种关闭方式：

| 方式 | 操作 |
| --- | --- |
| 任务管理器 | 结束 `ChemLabBackend.exe` |
| 脚本 | 双击仓库里的 `scripts/stop-backend.bat`（可自行复制到桌面） |

> 安装目录受系统保护（写入需要管理员），所以这个脚本没有随安装包放进去。
> 需要的话从仓库复制一份即可。

### 想用回原来的窗口模式

设置环境变量后启动：

```bat
set CHEMLAB_MODE=window
"C:\Users\<你>\AppData\Local\合记 ChemLab\heji-toolbox.exe"
```

窗口模式下所有功能都在（包括 PDF 导出、计时器通知），代价是 WebView2 的内存。

### 再次双击图标会怎样

如果后端已经在跑，启动器会**复用**它（不重复启动），直接打开浏览器然后退出。
所以多点几次图标不会出现"端口被占用"。

## 八、构建注意事项（踩过的坑）

改过 `build/ChemLab.spec` 的 `datas` 之后，**只跑 `npx tauri build` 是不够的** ——
它不会重新打包 Python sidecar，安装包里还是旧后端，`/toolbox/` 和
`/api/sop/*` 会全部 404。

必须跑完整流程：

```bat
powershell -ExecutionPolicy Bypass -File build\build.ps1 -Fast
```

**验证是否打对了**：装完后检查
`%LOCALAPPDATA%\合记 ChemLab\resources\backend\_internal\` 下是否有
`frontend-toolbox\index.html` 与 `assets\sops`。

> 本机额外遇到：PyInstaller 清理旧输出目录（1500+ 文件）会被安全策略拦。
> 绕过方式是先把 `build\dist\ChemLabBackend` 移走再构建。
