# P4 导航整合：统一信息架构与视觉

> 阶段：P4　｜　状态：已完成　｜　依据：`docs/三应用整合方案.md` 4.7 节

## 目标

P0～P3 把「数据」和「进程」理顺了：统一 schema、化学数据单一真源、后端收进主壳。
但**界面还是两个应用的拼贴**——工具箱是靛蓝 + 顶部 6 Tab，ChemELN 是 Ant Design 蓝 + 左侧栏，
用户看到的是两套设计语言、两套导航逻辑。

P4 把它收敛成一套：

- 统一信息架构：顶部主导航 9 个一级入口，按「工作台 / 工具 / 实验 / 设置」分组
- 工作台聚合：首页变成「入口 + 最近在做什么」
- 视觉收敛：色板、圆角、阴影统一到合迹（Ant Design）风格
- 实验记录接入：iframe 嵌入合迹前端，顶部分段器控制视图

## 视觉统一

色板对齐合迹（Ant Design），改主色只需改 `src/App.vue` 的 `:root`：

| 变量 | 旧值（工具箱） | 新值（统一） |
| --- | --- | --- |
| `--primary` | `#4f46e5`（靛蓝） | `#1677ff`（Ant Design 蓝） |
| `--bg` | `#f6f7fb` | `#f5f5f5` |
| `--text` | `#111827` | `#1f1f1f` |
| `--muted` | `#6b7280` | `#666666` |
| `--border` | `#e5e7eb` | `#f0f0f0` |
| `--danger` | `#dc2626` | `#ff4d4f` |
| `--ok` | `#16a34a` | `#52c41a` |
| 圆角 | 12px 为主 | 8px（`--radius`） |

新增 `--primary-dark` / `--primary-soft` / `--warning` / `--radius-sm` / `--shadow` / `--shadow-lg`
等 token，与合迹的变量名一一对应。

**为什么改色板成本这么低**：工具箱 11 个页面里硬编码的品牌色只有 0 处
（`#ffffff` 是按钮文字色，无害）。圆角则散落着 12px/10px/6px，已统一替换为变量。

深色模式保留工具箱方案（合迹没有），变量同步换成 Ant Design 深色版。

## 实验记录接入（P4 过渡方案）

P4 先用 **iframe**，P5 换 Tauri 原生子 webview —— 本组件对外接口不变，切换成本最小。

```
┌─ LabView.vue（Vue）──────────────────────────┐
│ 顶部分段器 仪表盘│实验记录│看板│化合物库│…      │
│ ┌─ iframe ────────────────────────────────┐  │
│ │ http://127.0.0.1:8765/  （合迹前端）     │  │
│ └──────────────────────────────────────────┘  │
└──────────────────────────────────────────────┘
```

**通信协议**（`postMessage`）：

| 方向 | 消息 |
| --- | --- |
| 主壳 → 子页 | `{ type:'chemlab:invoke', id, method:'navigate', params:{ view } }` |
| 子页 → 主壳 | `{ type:'chemlab:response', id, ok:true }` |

子页侧实现在 `frontend-chemeln/js/app.js` 的 `init()` 里（约 25 行），
只接受本机来源（`127.0.0.1` / `localhost` / `tauri.localhost`）。

**为什么 iframe 里的子页仍能拿到令牌**：子页与后端同源（都是 `127.0.0.1:8765`），
`/api/session` 是免鉴权路径，`api.js` 引导一次拿到令牌后用 header 提交。
iframe 是跨站上下文，`SameSite=Lax` 的 cookie 不会带过去 —— 所以**必须走 header，不能只靠 cookie**，
这一点合迹前端的 `api.js` 本来就是这么做的。

**后端静态服务打通**：`backend/config.py` 的 `frontend_dir()` 原本只找 `frontend/`
（打包模式解压目录），仓库里不存在，导致后端没有可托管的前端。
现在按 `frontend/` → `frontend-chemeln/` 顺序回退，合迹前端由后端根路径提供。
