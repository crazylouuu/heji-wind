## 风险

> 本页为**通用操作填写示例**（流程通用，不针对任何具体反应或化学品）。
> 实际执行前请查所用溶剂与试剂的 SDS，并按本单位标准操作规程操作。
> 萃取溶剂（乙酸乙酯/二氯甲烷等）易燃或有刺激性：通风、远离明火、戴手套。

## 器材与试剂

| 物品 | 说明 |
| --- | --- |
| 分液漏斗 | 容量约为反应液体积的 2 倍以上 |
| 萃取溶剂 | 乙酸乙酯 / 二氯甲烷 / 乙醚等，按产物极性选择 |
| 饱和食盐水 | 洗涤有机相、破乳化 |
| 干燥剂 | 无水硫酸钠（Na2SO4）或无水硫酸镁（MgSO4） |
| 旋转蒸发仪 | 浓缩有机相 |

## 步骤

1. 反应结束后先判断是否需要淬灭：若体系含水溶性酸碱/还原剂等活性物，先用对应淬灭剂小心处理（示例：缓慢滴加，搅拌至不再放气）
2. 将反应液转移至分液漏斗，加入萃取溶剂与水（萃取溶剂的选择：产物在有机相、杂质在水相）
3. 盖紧瓶塞振摇混合，**每振摇几下倒置放气一次**（防溶剂蒸气压力喷溅）；静置分层
4. 收集有机相；水相再用新溶剂萃取 2 次
5. 合并有机相，用饱和食盐水洗涤 1 次，静置分层后取有机相
6. 加入干燥剂（至不再结块），静置 15–30 min
7. 过滤除去干燥剂，旋转蒸发浓缩至干或近干，得粗产物

## 排错

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 乳化严重、分层慢 | 振摇过猛、体系含表面活性物 | 静置更久、加饱和食盐水、必要时离心或过滤 |
| 产物出现在水相 | pH 不合适或溶剂极性选错 | 调整水相 pH、换极性更大的溶剂、连续萃取 |
| 旋蒸暴沸/飞溅 | 真空降太快、溶剂残留过多 | 缓慢降压、加沸石、先常压蒸去大部分溶剂 |
| 干燥后仍浑浊 | 干燥剂不足或水过多 | 换新干燥剂再干燥，过滤 |
